# Beach Tennis Control — PWA

Conteúdo:
- index.html: aplicação baseada no HTML corrigido
- manifest.webmanifest: configuração PWA
- sw.js: cache/offline
- icons/: ícones para instalação

Para instalar no iPhone:
1. Publique esta pasta em um endereço HTTPS.
2. Abra o endereço no Safari do iPhone.
3. Toque em Compartilhar.
4. Escolha "Adicionar à Tela de Início".

Observação: o Service Worker e a instalação PWA exigem HTTPS (ou localhost durante desenvolvimento).
